SAVANNA BREW CAFE WEBSITE
=========================

Project contents
- index.html       Home page
- about.html       Café story and values
- menu.html        Menu tables and KES prices
- gallery.html     Responsive photo gallery
- contact.html     Contact details, opening hours and reservation form
- css/style.css    Shared external stylesheet
- images/          Local image assets and logo

How to view
1. Extract the ZIP file.
2. Open index.html in a modern web browser.
3. Use the navigation menu to visit the other pages.

Implementation notes
- Built with HTML5 and CSS only. No JavaScript or CSS frameworks are used.
- Shared navigation and footer appear on all five pages.
- CSS Flexbox is used for the navigation and CSS Grid for cards, values and gallery.
- The stylesheet contains CSS custom properties, hover/focus states, transitions and responsive breakpoints at 768px and 480px.
- The contact form uses browser-native required-field validation. Its mailto action opens the visitor's configured email application; it is a front-end demonstration and does not store reservations on a server.
- The café contact details and business story are fictional assignment content.

Validation checklist before submission
- Open each page and test every navigation link.
- Check the site at desktop, tablet and mobile widths.
- Validate each HTML page at https://validator.w3.org/
- Validate css/style.css at https://jigsaw.w3.org/css-validator/
- Review any warnings reported by the validators and record the results here before final submission.
